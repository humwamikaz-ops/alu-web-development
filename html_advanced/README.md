# HTML Advanced

A pure HTML project where I build the semantic structure of a webpage from a designer file (Figma). There is no CSS and no styling at this stage, only the HTML skeleton.

![Page preview](https://placehold.co/800x400?text=HTML+Advanced+Project)

## Objectives

- Read a designer file and turn it into semantic HTML
- Use the right heading levels (`h1`, `h2`, `h3`)
- Structure a page with `header`, `main`, `section` and `footer`
- Use `div` blocks, images, links, buttons and quotes correctly

## Page structure

1. **Header**: clickable logo and 3 navigation links
2. **Banner**: main title, text, button and 4 feature items
3. **Quote**: image, quote, author and subtitle
4. **Videos**: 4 video items with author and star rating
5. **Membership**: 4 plan items and a button
6. **FAQ**: 2 rows of 2 questions and answers
7. **Footer**: logo, social links and a text

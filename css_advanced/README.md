# CSS Advanced

Styling of the Smile School page from the previous HTML advanced project, built from a Figma designer file using only CSS.

![Page preview](https://placehold.co/800x400?text=Smile+School+Preview)

## Objectives

- Turn a designer file into pixel-conscious CSS
- Use Flexbox for layout and alignment
- Keep selectors simple and reuse shared styles
- Deploy the page with GitHub Pages

## Sections styled

1. Header and banner
2. Quote
3. Popular videos
4. Membership
5. FAQ
6. Footer

## Files

- `index.html`: the full page
- `styles.css`: all the styling
